# Ramanujan-type congruences for the smallest parts function

**Assembled by AxiomProver.**

Lean formalization of Larry Rolen’s *Ramanujan-type congruences for the smallest
parts function*.

The library proves the manuscript’s noncanonical exclusion, simple-congruence
classification, propagation, square-coefficient relation, CM separation and
character obstruction from named literature inputs. These inputs retain `sorry`
proofs; their precise statements, citations and qualifications are recorded in
[ASSUMPTIONS.md](ASSUMPTIONS.md).

Using the pinned Lean and mathlib versions, build with:

```sh
lake build SptClassification
```

Bibliographic references are collected in [references.bib](references.bib).
